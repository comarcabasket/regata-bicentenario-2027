# Regata del Bicentenario 2027

Sitio oficial de la 51.ª Regata Internacional del Río Negro, Regata del Bicentenario.

La web contiene etapas, historia, reglamento, galería fotográfica y redes sociales. Los enlaces externos de Inscripciones y Tiempos se agregarán cuando sean provistos por la organización.

Proyecto estático preparado para Cloudflare Pages (rama `main`, sin comando de compilación).
